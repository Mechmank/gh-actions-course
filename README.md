# GitHub Actions Course

A hands-on repository to accompany the GitHub Actions course on Udemy, focusing on automating workflows and CI/CD pipelines.

## 📋 Overview

This repository is structured to provide practical examples and exercises for learners to understand and implement GitHub Actions effectively. It covers various topics, including using actions, caching dependencies, and deploying applications.

## 🚀 Features

- **Workflow Examples**: Demonstrates the use of GitHub Actions in real-world scenarios.
- **React Application**: Includes a sample React app to practice CI/CD pipelines.
- **Caching**: Shows how to cache dependencies to speed up workflows.
- **Modular Structure**: Organized directories for each topic to facilitate learning.

## 📁 Repository Structure

```
gh-actions-course/
├── .github/
│   └── workflows/          # Contains workflow YAML files
├── 04-using-actions/
│   └── react-app/          # React app for practicing actions
├── 13-caching/
│   └── react-app/          # React app for caching example
└── README.md               # Project documentation
```

## 🛠️ Getting Started

### Prerequisites

- Git installed on your machine
- Node.js and npm for running the React applications
- A GitHub account

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Mechmank/gh-actions-course.git
   ```

2. Navigate to a specific example directory:
   ```bash
   cd gh-actions-course/04-using-actions/react-app
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm start
   ```
